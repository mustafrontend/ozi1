## Setup

1. Create a Vite + React + Tailwind project (`npm create vite@latest`)
2. Import `tokens.css` in your app entry; map the CSS variables in tailwind.config
3. Install icons: `npm install @iconify/react` (icons keep their Iconify names)
4. Requires React 18+ / Tailwind CSS 3.4+
